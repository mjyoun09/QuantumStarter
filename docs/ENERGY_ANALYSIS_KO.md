# 반응·흡착에너지와 결과 비교

GUI **실행 기록 → 흡착에너지 분석** 또는 `energy_analysis.py`를 사용한다.
기본 정의는 E_ads=E(촉매+흡착종)−E(촉매)−f×E(흡착종 기준)이며 f 기본값은1이다.
예를 들어 H 원자1개의 기준을 H₂로 잡을 때는 f=0.5다. 원소 수지가 맞지 않으면 계산을 거부한다.

음수는 선택한 기준에서 전자 에너지가 낮아지는 흡착이다. 흡착에너지만으로 활성·선택성·연료 생산 효율을
입증했다고 해석하지 않는다. 진동 ZPE/열역학/반응 장벽/동역학을 자동 포함하지 않는다.

검사: 모든 입력의 SCF 수렴, 유한한 에너지, 원소·전체 전하 수지, 엔진/기저/XC/적분 격자/SCF 에너지 허용오차,
상대론/핵/ECP 정책, 가능한 Libxc 버전/함수 ID. 주기계는 셀·경계·k점·smearing·정밀도와 입력 셀당 에너지 규약도
같아야 한다. 분자 RKS/UKS와 스핀은 반응물/생성물에 따라 달라도 된다. 원자 좌표는 달라도 된다.

현재는 같은 주기 셀에서 계산한 참조만 허용한다. 다른 셀의 기체 참조를 결합하는 보정은 미지원이다.
자체/외부/ML 에너지를 섞어 반응에너지를 만들지 않는다. 체크포인트의 엔진 간 밀도 전달과 에너지 출처 혼합은 별개다.
서로 다른 조건의 계산을 보고 싶으면 **기록 다중 선택 → 선택한 기록 비교**로 원시 결과와 조건을 나란히 확인한다.

결과는 `outputs/analysis/고유폴더/analysis.json`에 저장한다. 각 항의 계수·원소식·전하·스핀·에너지·엔진과
원본 결과파일 경로/SHA256, 실제 적용 조건, 에너지 정의와 한계를 보존한다. 기존 연구 결과를 덮어쓰지 않는다.

```powershell
.\.venv\Scripts\python.exe energy_analysis.py --combined <복합계폴더> --substrate <기판폴더> --adsorbate <기준폴더> --factor 0.5
.\.venv\Scripts\python.exe energy_analysis.py --terms reaction.json
```

`reaction.json`은 생성물 계수 양수, 반응물 음수인 배열이다:

```json
[{"coefficient":1,"path":"H2_실행폴더"},{"coefficient":-2,"path":"H_실행폴더"}]
```

실제 자체 LDA/STO-3G/grid2 데이터로 H₂−2H를 계산해 −6.799190445 eV를 얻었다.
`outputs/analysis/20261029_195626_hr778v3r/analysis.json`에 저장했다. 이는 부호·수지·출처·합산 경로 검증용이며
실험적 H₂ 결합에너지의 정확도 기준값이 아니다. 합산 단위 테스트2개는 조건 불일치/미수렴/수지 오류의 거부도 확인한다.
